# Decision-Log Rotation and History Reading Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bound the unbounded growth of the decision log by rotating it into gzipped segments, while teaching the drift baseline to read the full segment history — so compression never costs the daemon a day of learned normal.

**Architecture:** `decisionlog.Writer` gains size-triggered rotation: when the live file passes a threshold, it is renamed to a timestamp-suffixed segment (`blocked.log.20260815T031422Z`), a fresh live file is opened, and the renamed segment is gzipped in the background to `<name>.gz` via a `.gz.tmp` plus atomic rename, so no reader ever sees a partial archive. A new `decisionlog.ReadHistory` reads every segment oldest-to-newest followed by the live file, transparently decompressing `.gz`; the existing `Read` keeps its cheap single-file semantics for the menu bar and `tail`. `internal/cli/loadOrBuildBaseline` switches to `ReadHistory` — it is the only consumer that needs history. Retention is a knob defaulting to unlimited: compression is not data loss, deletion is.

**Tech Stack:** Go 1.22 (module floor), `compress/gzip` + `os` + `path/filepath` + `sort` + `strings` (all stdlib). No new module dependencies.

**Source spec:** `byliu-labs/egress-guard-private` → `strategy/2026-08-15-behavioral-dimension-premise-revision.md` §6 and §11 item 1.

**Why this is first:** the log has no rotation today and grows without bound (measured 461 B/entry, ~3.4 GB/yr at 20k connections/day). The flow records planned next make it grow faster, so this lands ahead of them.

## Definition of Done

All six tasks complete, `make build` and `make test` green, and the following observable end state holds:

1. A `Writer` whose live file passes `MaxBytes` produces a timestamped segment and a fresh live file, losing no entry.
2. Rotated segments end up gzipped on disk, and a crash between rename and compression is repaired at the next `Open`.
3. `decisionlog.ReadHistory` returns every entry across every segment plus the live file, oldest first.
4. `internal/cli/loadOrBuildBaseline` builds the drift baseline from that full history, so a pair whose two qualifying days straddle a rotation boundary is still classified `drift.ClassKnown`.
5. `egress-guard status` reports the decision log's segment count and total bytes.

Point 4 is the reason this plan exists. A run that stops after point 3 has shipped storage plumbing and no guarantee.

```go
package decisionlog

import (
	"path/filepath"
	"sort"
	"strings"
	"time"
)

// segmentTimeFormat is fixed-width and UTC so lexicographic order on the
// filename equals chronological order. Nothing may parse it back for sorting.
const segmentTimeFormat = "20060102T150405Z"

// gzSuffix marks a compressed segment.
const gzSuffix = ".gz"

// segmentName is the path a live log is renamed to when it rotates at t.
func segmentName(base string, t time.Time) string {
	return base + "." + t.UTC().Format(segmentTimeFormat)
}

// findSegments returns rotated segment paths for base, oldest first. The live
// file (base itself) is never included, and neither is anything whose suffix is
// not one of our timestamps — an external rotator's blocked.log.1 is not ours.
//
// When a crash leaves both the plain and the compressed form of one timestamp
// on disk, the compressed one wins and the plain one is dropped: compression
// finishes with an atomic rename, so a .gz that exists is always complete.
func findSegments(base string) ([]string, error) {
	matches, err := filepath.Glob(base + ".*")
	if err != nil {
		return nil, err
	}
	byStamp := map[string]string{}
	for _, m := range matches {
		if m == base {
			continue
		}
		stamp := strings.TrimPrefix(m, base+".")
		stamp = strings.TrimSuffix(stamp, gzSuffix)
		if len(stamp) != len(segmentTimeFormat) {
			continue
		}
		if _, err := time.Parse(segmentTimeFormat, stamp); err != nil {
			continue
		}
		if existing, ok := byStamp[stamp]; ok && strings.HasSuffix(existing, gzSuffix) {
			continue
		}
		byStamp[stamp] = m
	}
	out := make([]string, 0, len(byStamp))
	for _, p := range byStamp {
		out = append(out, p)
	}
	sort.Slice(out, func(i, j int) bool {
		return strings.TrimSuffix(out[i], gzSuffix) < strings.TrimSuffix(out[j], gzSuffix)
	})
	return out, nil
}
```

```go
package decisionlog

import (
	"compress/gzip"
	"errors"
	"fmt"
	"io"
	"os"
	"strings"
)

// ReadHistory parses every decision-log entry available on disk — each rotated
// segment oldest first, then the live file at path. Use it wherever the full
// learned history matters (the drift baseline); use Read when only the live
// file is wanted (the menu bar, tail), because decompressing the whole archive
// on a UI timer is wasteful.
//
// A missing live file is not an error when rotated segments exist: the daemon
// may not have reopened it yet. Nothing on disk at all returns an error
// wrapping os.ErrNotExist, matching Read.
func ReadHistory(path string) ([]Entry, error) {
	segments, err := findSegments(path)
	if err != nil {
		return nil, fmt.Errorf("decisionlog: find segments for %s: %w", path, err)
	}
	var all []Entry
	for _, seg := range segments {
		entries, err := readSegment(seg)
		if err != nil {
			return nil, err
		}
		all = append(all, entries...)
	}
	live, err := Read(path)
	if err != nil {
		if len(segments) > 0 && errors.Is(err, os.ErrNotExist) {
			return all, nil
		}
		return nil, err
	}
	return append(all, live...), nil
}

// readSegment reads one rotated segment, decompressing when it is gzipped.
func readSegment(path string) ([]Entry, error) {
	if !strings.HasSuffix(path, gzSuffix) {
		return Read(path)
	}
	f, err := os.Open(path)
	if err != nil {
		return nil, fmt.Errorf("decisionlog: open segment %s: %w", path, err)
	}
	defer f.Close()
	zr, err := gzip.NewReader(f)
	if err != nil {
		return nil, fmt.Errorf("decisionlog: gzip reader %s: %w", path, err)
	}
	defer zr.Close()
	raw, err := io.ReadAll(zr)
	if err != nil {
		return nil, fmt.Errorf("decisionlog: decompress %s: %w", path, err)
	}
	return parseEntries(string(raw), path)
}
```

```go
// Read parses every entry in the live decision log at path, in file order. It
// does not consult rotated segments; see ReadHistory for the full history.
func Read(path string) ([]Entry, error) {
	b, err := os.ReadFile(path)
	if err != nil {
		return nil, fmt.Errorf("decisionlog: read %s: %w", path, err)
	}
	return parseEntries(string(b), path)
}

// parseEntries turns JSONL text into entries. A corrupt trailing line is a torn
// final write and is dropped; a corrupt line anywhere else is an error.
func parseEntries(text, path string) ([]Entry, error) {
	trimmed := strings.TrimRight(text, "\n")
	if trimmed == "" {
		return nil, nil
	}
	lines := strings.Split(trimmed, "\n")
	entries := make([]Entry, 0, len(lines))
	for i, line := range lines {
		var e Entry
		if err := json.Unmarshal([]byte(line), &e); err != nil {
			if i == len(lines)-1 {
				break
			}
			return nil, fmt.Errorf("decisionlog: corrupt entry at line %d of %s: %w", i+1, path, err)
		}
		entries = append(entries, e)
	}
	return entries, nil
}
```

```go
// DefaultMaxBytes is the live-file size that triggers rotation. At the measured
// ~461 bytes per entry this is roughly 145k entries — about a week of traffic
// on a busy developer machine.
const DefaultMaxBytes int64 = 64 << 20

// Options tunes rotation. The zero value means defaults: rotate at
// DefaultMaxBytes, keep every segment forever, use the wall clock.
type Options struct {
	// MaxBytes is the live-file size at which rotation happens. Negative
	// disables rotation entirely; zero means DefaultMaxBytes.
	MaxBytes int64
	// MaxSegments caps retained rotated segments, oldest deleted first. Zero
	// means unlimited — compression is not data loss, deletion is, so the
	// default never destroys history.
	MaxSegments int
	// Now is the clock used for segment timestamps; nil means time.Now.
	Now func() time.Time
}

func (o Options) withDefaults() Options {
	if o.MaxBytes == 0 {
		o.MaxBytes = DefaultMaxBytes
	}
	if o.Now == nil {
		o.Now = time.Now
	}
	return o
}

// OpenWithOptions opens the decision log with explicit rotation settings.
func OpenWithOptions(path string, opts Options) (*Writer, error) {
	w, err := openWriter(path)
	if err != nil {
		return nil, err
	}
	w.opts = opts.withDefaults()
	fi, err := w.f.Stat()
	if err != nil {
		w.f.Close()
		return nil, fmt.Errorf("decisionlog: stat %s: %w", path, err)
	}
	w.size = fi.Size()
	return w, nil
}

// rotateLocked renames the live file to a timestamped segment and reopens a
// fresh one. The caller must hold w.mu. It is deliberately cheap — a rename and
// an open — so the write path is never blocked by compression.
func (w *Writer) rotateLocked() error {
	if err := w.f.Close(); err != nil {
		return fmt.Errorf("decisionlog: close before rotate: %w", err)
	}
	seg := segmentName(w.path, w.opts.Now())
	if err := os.Rename(w.path, seg); err != nil {
		// Reopen so the daemon keeps logging even when rotation failed.
		if f, oerr := os.OpenFile(w.path, os.O_APPEND|os.O_CREATE|os.O_WRONLY, 0o644); oerr == nil {
			w.f = f
		}
		return fmt.Errorf("decisionlog: rotate rename: %w", err)
	}
	f, err := os.OpenFile(w.path, os.O_APPEND|os.O_CREATE|os.O_WRONLY, 0o644)
	if err != nil {
		return fmt.Errorf("decisionlog: reopen after rotate: %w", err)
	}

	w.size = 0
```

```go
// Writer wraps the underlying file with a mutex for goroutine-safe appends.
type Writer struct {
	mu   sync.Mutex
	f    *os.File
	path string
	size int64
	opts Options
}

// Open opens, creating if needed, the append-only log file at path, with
// default rotation settings.
func Open(path string) (*Writer, error) {
	return OpenWithOptions(path, Options{})
}

// openWriter creates the file handle without applying rotation settings.
func openWriter(path string) (*Writer, error) {
	if err := os.MkdirAll(filepath.Dir(path), 0o755); err != nil {
		return nil, fmt.Errorf("decisionlog: mkdir: %w", err)
	}
	f, err := os.OpenFile(path, os.O_APPEND|os.O_CREATE|os.O_WRONLY, 0o644)
	if err != nil {
		return nil, fmt.Errorf("decisionlog: open: %w", err)
	}
	return &Writer{f: f, path: path}, nil
}

// Write appends one entry as one mutex-guarded write, rotating first when the
// live file has reached Options.MaxBytes. The w.size > 0 condition means a
// single entry larger than MaxBytes is written rather than triggering an
// endless rotate-on-every-write loop against an empty file.
func (w *Writer) Write(e Entry) error {
	if e.Timestamp == "" {
		e.Timestamp = time.Now().UTC().Format(time.RFC3339)
	}
	b, err := json.Marshal(e)
	if err != nil {
		return fmt.Errorf("decisionlog: marshal: %w", err)
	}
	b = append(b, '\n')

	w.mu.Lock()
	defer w.mu.Unlock()
	if w.opts.MaxBytes > 0 && w.size > 0 && w.size+int64(len(b)) > w.opts.MaxBytes {
		if err := w.rotateLocked(); err != nil {
			return err
		}
	}
	n, err := w.f.Write(b)
	w.size += int64(n)
	if err != nil {
		return fmt.Errorf("decisionlog: write: %w", err)
	}
	return nil
}
```

```go
// compressSegment gzips path to path+".gz" and removes the plain file. It
// writes to a .gz.tmp first and renames, so a reader never observes a partial
// archive — which is what lets findSegments trust any .gz it finds.
func compressSegment(path string) error {
	in, err := os.Open(path)
	if err != nil {
		return fmt.Errorf("decisionlog: compress open %s: %w", path, err)
	}
	defer in.Close()

	tmp := path + gzSuffix + ".tmp"
	out, err := os.Create(tmp)
	if err != nil {
		return fmt.Errorf("decisionlog: compress create %s: %w", tmp, err)
	}
	zw := gzip.NewWriter(out)
	if _, err := io.Copy(zw, in); err != nil {
		zw.Close()
		out.Close()
		os.Remove(tmp)
		return fmt.Errorf("decisionlog: compress copy %s: %w", path, err)
	}

		out.Close()
		os.Remove(tmp)
		return fmt.Errorf("decisionlog: compress finish %s: %w", path, err)
	}
	if err := out.Close(); err != nil {

		return fmt.Errorf("decisionlog: compress close %s: %w", tmp, err)

		os.Remove(tmp)

	}
	if err := os.Remove(path); err != nil {
```

```go
// logFootprint reports how many rotated segments exist and the total bytes the
// decision log occupies on disk, live file included. A missing log is (0, 0),
// not an error — a machine that has never run the daemon is not a failure.
// In-flight .gz.tmp files are skipped: they are mid-compression, not segments.
func logFootprint(logPath string) (int, int64, error) {
	var total int64
	if fi, err := os.Stat(logPath); err == nil {
		total += fi.Size()
	} else if !os.IsNotExist(err) {
		return 0, 0, err
	}
	matches, err := filepath.Glob(logPath + ".*")
	if err != nil {
		return 0, 0, err
	}
	segments := 0
	for _, m := range matches {
		if strings.HasSuffix(m, ".tmp") {
			continue
		}
		fi, err := os.Stat(m)
		if err != nil {
			if os.IsNotExist(err) {
				continue
			}
			return 0, 0, err
		}
		segments++
		total += fi.Size()
	}
	return segments, total, nil
}
```
